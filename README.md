# Pruebas iPad (SwiftUI)

App de prueba para iPad hecha en SwiftUI, en formato de proyecto de **Swift Playgrounds** (`PruebasiPad.swiftpm`).
No necesitas Mac: se abre y se ejecuta directo en el iPad.

## Secciones

- **Tareas**: lista con agregar, marcar, borrar (deslizar) y reordenar (Editar). Se guarda al cerrar la app.
- **Dibujo**: lienzo para dedo o Apple Pencil, con color, grosor, deshacer y borrar.
- **Gestos**: arrastrar, pellizcar para hacer zoom y girar con dos dedos. Doble toque para reiniciar.
- **Dispositivo**: modelo, versión de iPadOS, tamaño de la pantalla, orientación, apariencia y batería.

## Cómo abrirla en el iPad

1. Instala **Swift Playgrounds** desde la App Store (es gratis, requiere iPadOS 17 o superior).
2. Descarga el ZIP de esta rama en GitHub (**Code → Download ZIP**) desde Safari en el iPad.
3. Abre la app **Archivos**, toca el ZIP para descomprimirlo y luego toca `PruebasiPad.swiftpm`; se abrirá en Swift Playgrounds.
4. Toca ▶︎ para ejecutarla. Con **Archivo → Instalar en pantalla de inicio**, aparece como una app más.

## En una Mac (opcional)

Abre `PruebasiPad.swiftpm` con Xcode 15 o superior y ejecútala en el simulador de iPad.
